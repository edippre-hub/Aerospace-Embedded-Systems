Aerospace Embedded Software Engineering Project – C++ and Real-Time Systems

Designed and developed an aerospace embedded software simulation platform using C++17, 
Linux, and real-time operating system concepts.

Applied the complete Software Development Life Cycle (SDLC), including requirements 
analysis, software architecture, design, implementation, integration, verification, and validation.

Developed modular object-oriented C++ software using inheritance, polymorphism, templates, 
STL containers, and memory management.

Designed embedded software architecture incorporating hardware abstraction layers, 
sensor interfaces, device-driver concepts, and processor communication.

Implemented real-time task scheduling, multithreading, synchronization,
message queues, semaphores, and watchdog monitoring.

Explored ARM processor architecture, memory management, GPIO, UART, SPI, and I2C interfaces.

Developed automated unit and integration testing using GoogleTest.

Applied fault injection, error handling, performance testing, and software verification techniques.

Implemeted software build automation, source control, Docker-based testing, 
and CI/CD pipelines using GitHub Actions.

Technologies: C++, CMake, Linux, FreeRTOS, ARM, Python, Git, Docker,
GoogleTest, GCC, GDB, GitHub Actions.
